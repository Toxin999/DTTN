# DetectiveNet — agent notes

Detective game (demo: 1-2 h) set inside a fictional 2002 desktop OS. The player
never leaves the screen of a simulated home computer: web forums, IM, email,
logs, and light hacking minigames. Godot 4.6, 2D/UI only, GL Compatibility.

## Run / verify

```
Godot --path .                                             # boot -> desktop
./tools/run_tests.sh                                       # all selftests
Godot --path . --quit-after 700  res://spikes/shell/boot_selftest.tscn
Godot --path . --quit-after 1400 res://spikes/shell/shell_selftest.tscn
Godot --path .                   res://spikes/text/spike_text.tscn
python3 tools/gen_ui_assets.py                             # regenerate UI art
python3 tools/process_photo.py --self-test                 # photo pipeline
python3 tools/process_photo.py scan|digicam|both assets/photos/raw/*.jpg
```

Selftests print `SELFTEST ... (expect ...)` lines and save PNGs to
`spikes/out/` (git-ignored). Captures are the acceptance evidence — read them.
Dev captures disable `OS.low_processor_usage_mode` so redraws always happen.

## Hard-won gotchas

- Embedded subwindows (`Window` nodes) render above **every** CanvasLayer.
  Overlays (taskbar, start menu, dialogs) must be `Window` nodes and are
  restacked with `move_child(overlay, -1)`.
- `Window.move_to_foreground()` is deprecated in 4.6 — `grab_focus()` brings
  a window to the front. Unfocusable overlays use `move_child` instead.
- `Window.position` / `Window.size` are `Vector2i` — convert explicitly.
- Themes do **not** propagate into embedded windows; assign the shared theme
  to each Window (`WindowManager` does this via `UiTheme.build()`).
- The runtime low-processor switch is `OS.low_processor_usage_mode`
  (there is no `Engine.low_processor_usage_mode` in Godot 4).
- `Window` already defines `close_requested`; don't redeclare it. Avoid
  overriding native methods (`set_title`, ...) — warnings are treated as
  errors here.
- Thai text needs `TextServer.AUTOWRAP_WORD_SMART` (ICU word breaking);
  fonts are PT Sans + Sarabun fallback, built in `UiTheme`.
- Legal: everything fictional. No Microsoft assets, logos, or startup chime
  melodies. UI art is generated by `tools/gen_ui_assets.py` (Pillow).

## Layout

```
scenes/main.tscn          boot -> desktop entry point
src/core/                 settings (user://settings.cfg), world_clock, ui_theme
src/shell/                desktop, window_manager, wexp_window, taskbar, start_menu
src/apps/                 app_base + browser/mail/settings (Phase 1 placeholders)
content/en/               narrative source (style guide lives here)
tools/                    Pillow generators: UI art, era photo processing
spikes/                   dev-only selftests + capture helper (spike_text kept)
```
